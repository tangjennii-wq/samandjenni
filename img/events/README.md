# Event card photos

Drop five JPGs in this folder and the cards on weekend.html pick them up
automatically. Until a file exists the card falls back to a tinted S ♥ J panel,
so a missing photo never looks broken.

| filename            | card              | suggested shot                    |
|---------------------|-------------------|-----------------------------------|
| `thursday.jpg`      | Welcome dinner    | an engagement photo, downtown      |
| `rehearsal.jpg`     | Rehearsal dinner  | Chinese Tuxedo interior            |
| `welcome-party.jpg` | Welcome party     | Doyers St / Chinatown at night     |
| `wedding.jpg`       | The wedding       | The Pierre exterior or ballroom    |
| `brunch.jpg`        | Farewell brunch   | a softer, morning-light engagement |

Landscape, roughly 4:3, at least 1200px wide. They're cropped to fill, so keep
faces near the centre. Compress to under ~400KB each.
