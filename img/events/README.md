# Event card photos

Drop five JPGs in this folder and the cards on weekend.html pick them up
automatically. Until a file exists the card falls back to a tinted S ♥ J panel,
so a missing photo never looks broken.

This file is in a PUBLIC repo and is served at /img/events/README.md, so it
must not name venues, addresses, times, or which guests see which card.

| filename            | suggested shot                     |
|---------------------|------------------------------------|
| `thursday.jpg`      | an engagement photo, downtown      |
| `rehearsal.jpg`     | a restaurant interior              |
| `welcome-party.jpg` | a street at night                  |
| `wedding.jpg`       | a hotel exterior or ballroom       |
| `brunch.jpg`        | a softer, morning-light engagement |

Landscape, roughly 4:3, at least 1200px wide. They're cropped to fill, so keep
faces near the centre. Compress to under ~400KB each.
