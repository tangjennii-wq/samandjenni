# Dress code inspiration

Drop images here as `look-01.jpg`, `look-02.jpg` … up to `look-16.jpg`.

The lookbook on weekend.html renders 16 slots; any slot with no file quietly
removes itself, and if none of them load the whole section stays hidden. So you
can add two now and fourteen later without touching any code.

Portrait, roughly 3:4, at least 800px wide, under ~300KB each.
